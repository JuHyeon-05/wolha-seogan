# 월하서간 · 무명의 공용 서고

할로윈의 밤과 조선의 풍경을 겹쳐 상상한 편지 서고입니다. 다시 만날 수 없는 이에게 남기는 편지를 기록의 신 무명이 지킵니다.

사이트: https://juhyeon-05.github.io/wolha-seogan/

## 공개 편지

편지를 쓰고 **공개 서고에 남기기**를 누르면 서버에 저장되어 누구나 읽을 수 있습니다. 별도의 내 서고 저장이나 링크 전달은 필요 없습니다. 답장도 공개되며, 같은 서간에 이어진 편지를 함께 읽을 수 있습니다. 편지 링크는 해당 공개 글로 바로 들어가는 주소입니다.

한 통에 최대 6,000자입니다. 장 나누기, 계절별 보기, 책갈피, 글씨 크기, 낮과 밤 테마, 무명의 기록 인장을 사용할 수 있습니다. 공개 서고는 30초마다 새 글을 확인하며, 새로 불러오기와 지난 서간 더 읽기를 지원합니다.

작성한 브라우저에만 보관되는 편지별 수정 권한으로 본인의 공개 편지를 수정·삭제합니다. 공개 편지의 수정은 다른 방문자에게도 반영되며, 삭제하면 공개 링크도 열리지 않습니다. 다른 사람이 이미 복사하거나 백업한 사본은 지워지지 않습니다.

## 개인 원고와 이전 편지

쓰던 원고는 자동으로 브라우저에 임시 보관되며 공개되지 않습니다. 이전 버전에서 개인 보관한 편지는 기존 개인 편지에 남고, 자동으로 서버에 업로드하지 않습니다. 이 편지를 수정한 뒤 공개하기를 누르거나 공개 서고에 맡기기를 선택한 경우에만 공개됩니다.

서고 설정의 백업에는 내가 남긴 편지, 원고, 책갈피, 설정과 편지 수정 권한이 포함됩니다. 브라우저 데이터를 지우면 개인 원고와 수정 권한을 잃을 수 있으므로 백업을 간직해 주세요. 백업은 비공개로 보관해야 합니다.

## 장지문 인트로

같은 브라우저 방문 중 처음 한 번, 밤빛 아래 장지문이 열리고 종잇장이 흩날립니다. 바로 들어가기로 건너뛸 수 있습니다. 움직임 줄이기 설정을 따르며, 편지로 직접 들어가는 링크에서는 읽기를 가리지 않습니다. 서고 설정에서 다시 볼 수 있습니다.

## 구성

프런트엔드는 GitHub Pages의 main 브랜치 최상위에서 배포합니다. index.html, desk.css, desk.js, shared-archive.js, .nojekyll을 함께 배포합니다. 사용자 편지나 수정 권한을 GitHub 소스에 저장하지 않습니다.

공개 데이터와 API는 Sites의 Cloudflare Workers 및 D1에서 보관합니다. 서버 소스와 마이그레이션의 Sites project_id는 appgprj_6ae5950df9e881918b52885ac83a1d4f입니다. 프런트엔드 API 주소는 shared-archive.js의 ARCHIVE_API입니다. 서버 API는 본문 길이, 작성자 권한, 수정 충돌을 검증하며 하루 작성 횟수를 제한합니다.

Sites API origin: https://wolha-seogan-public-archive.dreamydeer518.chatgpt.site

무명에게 맡기기는 창작 세계관 안의 상징적인 인장입니다. 인장과 날짜는 공개 편지 및 백업에 함께 남습니다. 예시 편지는 포함하지 않습니다.
