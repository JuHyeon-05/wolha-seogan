# 월하서간 月下書簡

조선의 작은 서고를 상상한 편지 읽기·쓰기 사이트입니다.

사이트: https://juhyeon-05.github.io/wolha-seogan/

저장소: https://github.com/JuHyeon-05/wolha-seogan

## 편지 주고받기

1. 사이트 상단의 **편지 쓰기**에서 보내는 이, 받는 이, 제목, 내용을 적습니다.
2. **편지 링크 만들기**를 누르고 링크를 복사해 카카오톡이나 메시지로 전달합니다.
3. 상대는 링크를 열어 편지를 읽고 **내 서고에 보관**하거나 **답장 쓰기**를 누릅니다.
4. 상대가 만든 답장 링크를 돌려받아 열고 보관하면, 원래 편지와 함께 이어 읽을 수 있습니다.

링크에는 해당 편지 한 통의 내용이 담깁니다. 앞선 대화 전문은 포함하지 않습니다. 링크를 가진 사람은 누구나 읽을 수 있으며, 이미 전달한 링크는 취소할 수 없습니다. 이름은 작성자가 직접 적으며 별도의 로그인이나 신원 확인은 없습니다.

답장이 자동으로 도착하는 서버 우체함은 아닙니다. 편지와 답장 링크는 사용자가 직접 전달합니다. 계정, 자동 수신, 기기 간 자동 동기화는 제공하지 않습니다.

## 나의 서고

- 받은 편지, 쓴 편지, 쓰던 편지, 책갈피, 계절별 분류
- 쓰던 편지 자동 임시 보관, 다시 열어 이어 쓰기
- 한 통에 최대 6,000자, 장 나누기, 방향키로 장 넘기기
- 같은 서간에 이어진 편지와 답장 찾아 읽기
- 사이트 안에서 이름과 호, 서고 이름, 첫 화면 문구, 소개, 글씨 크기, 줄 간격, 낮과 밤 테마 설정
- 쓴 편지와 쓰던 원고 수정·삭제, 삭제 전 확인
- 서고 백업 내려받기·가져오기

편지, 원고, 설정, 읽던 위치는 각 브라우저의 localStorage에 보관됩니다. 브라우저 데이터 삭제 시 함께 사라질 수 있으므로 설정의 백업 기능을 이용해 주세요. 백업에는 편지 내용이 포함됩니다. 가져오기는 기존 편지를 유지하며 없는 편지를 더하고, 설정은 백업에 맞춥니다.

## 개발 및 배포

빌드나 서버 설치가 필요 없는 정적 사이트입니다. index.html, desk.css, desk.js, .nojekyll을 함께 배포합니다. 로컬에서는 정적 HTTP 서버로 확인할 수 있습니다. 공유·복사는 HTTPS 배포 환경에서 사용하세요.

GitHub Pages는 main 브랜치의 최상위를 배포합니다. 사용자 편지는 저장소로 업로드되지 않습니다. 링크로 공유하는 편지는 URL의 fragment에 담기며, 사이트가 별도의 편지 저장 서버를 호출하지 않습니다.

외부 Google Fonts에 연결되지 않으면 기기의 바탕체로 표시합니다. 삽화와 화면 구조는 index.html에, 서고 기능은 desk.js와 desk.css에 있습니다. 기본 예시 편지는 포함하지 않습니다.

## 편지 수정·삭제

편지 카드의 수정·삭제 버튼으로 관리합니다. 쓴 편지는 읽기 화면에서도 수정할 수 있습니다. 수정 중인 원고는 쓰던 편지에 임시 보관하며, 저장을 마칠 때 원본이 바뀝니다. 원고만 삭제하면 원본은 유지합니다.

수정한 편지는 새 링크로 전달해야 합니다. 이전 링크에는 이전 내용이 남습니다. 상대는 새 링크를 열고 수정본으로 보관할 수 있습니다. 내 서고에서 삭제해도 이미 전달한 링크나 상대가 보관한 편지는 없어지지 않습니다.
